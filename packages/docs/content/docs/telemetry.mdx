`@uji-ai/telemetry` is the smallest contract the harness needs so every call site can already thread a parent through `Context`. Uji has no exporter. `NOOP_TELEMETRY_CONTEXT` records nothing. An OpenTelemetry implementation can replace it later without touching call sites.

```ts title="packages/telemetry/src/index.ts"
import { NOOP_TELEMETRY_CONTEXT, type TelemetryContext } from "@uji-ai/telemetry";

await parent.startSpan({ name: "harness.prompt" }, async (span) => {
  span.setAttributes({ sessionId: "…" });
});
```

`TelemetrySpan` is itself a `TelemetryContext`, so children parent on the live span. Core attaches the default no-op on every root `Context` via `withTelemetryContext`.

There is no sampling, no exporter, and no dashboard. The package exists so spans have a place to go when that work lands.
