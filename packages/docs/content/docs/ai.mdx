`@uji-ai/ai` is the provider layer. It does not register anything globally. A host constructs `Models`, attaches a credential store, registers the providers that product supports, and injects `models.streamSimple` as the loop's `StreamFn`.

```ts title="bind.ts"
import { createModels, FileCredentialStore, openaiCodexProvider } from "@uji-ai/ai";

const models = createModels({ credentials: new FileCredentialStore() });
const provider = openaiCodexProvider();
models.setProvider(provider);
const model = models.getModel(provider.id, "gpt-5.6-luna");
if (model === undefined) throw new Error("model unavailable");

const streamFn = (requestedModel, context, options) =>
  models.streamSimple(requestedModel, context, options);
```

## What it owns

| Area      | Symbols                                                                                                               |
| --------- | --------------------------------------------------------------------------------------------------------------------- |
| Registry  | `createModels`, `Models`, `getModel`, `setProvider`                                                                   |
| Providers | `openaiProvider`, `openaiCodexProvider`, `anthropicProvider`, `opencodeProvider`, `opencodeGoProvider`, Google Gemini |
| Auth      | `FileCredentialStore`, `anthropicOAuth`, `openaiCodexOAuth`, env API keys                                             |
| Stream    | `streamSimple`, `EventStream`, assistant-message framing                                                              |

The loop never imports a provider. It receives a `StreamFn`. [The stream function page](/docs/core/stream-fn) is the contract.
