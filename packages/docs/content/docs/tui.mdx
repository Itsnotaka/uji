`@uji-ai/tui` is the in-repo terminal client. It runs from source. `packages/tui/src/index.ts` is the entry: `login`, `logout`, `status`, `update`, `-p` print mode, and the interactive TUI. `update` (and `/update` in the TUI) self-replaces a compiled binary from GitHub Releases after verifying the sha256; from a source checkout it says so and does nothing.

```bash title="packages/tui"
pnpm --dir packages/tui start
pnpm --dir packages/tui start -- -p "list the TypeScript files here"
```

The client constructs `Models`, logs in through the provider's OAuth or API-key flow, and drives `AgentHarness` in-process. There is no wire. [Quickstart](/docs/quickstart) is the path from a clone to a streaming run.

## `uji-ai`

`packages/cli` publishes `uji-ai` as a placeholder that reserves the `uji` bin. It does not start an agent or a server. The published package will compose this TUI with `@uji-ai/server` when that package exists.

```sh title="placeholder"
npx uji-ai
npx uji-ai serve
```
