title: Stream function
description: Bind the provider-neutral agent loop to an @june/ai Models runtime

`StreamFn` is the only model boundary in `@june/core`:

```ts
type StreamFn = (
  model: Model<Api>,
  context: Context,
  options?: SimpleStreamOptions,
) => AssistantMessageEventStream | Promise<AssistantMessageEventStream>;
```

The loop owns turn and tool sequencing. The stream function owns one provider request. It receives the
selected model, the neutral conversation context, and request options, then returns the canonical assistant
event stream. Provider-specific request and response shapes stay inside `@june/ai`.

## Bind `Models.streamSimple`

`Models.streamSimple` already satisfies the contract and applies provider auth before dispatch. A host registers
the providers it supports, selects a concrete `Model<Api>`, and injects a small closure:

```ts
import { createModels, FileCredentialStore, openaiCodexProvider } from "@june/ai";

const models = createModels({ credentials: new FileCredentialStore() });
models.setProvider(openaiCodexProvider());

const model = models.getModel("openai-codex", "gpt-5.6-luna");
if (model === undefined) throw new Error("Model is unavailable");

const sessionId = "session-id";
const streamFn = (requestedModel, context, options) =>
  models.streamSimple(requestedModel, context, { ...options, sessionId });
```

The closure is host composition, not a second adapter. `Models` resolves credentials, merges request options,
selects the provider from `model.provider`, and delegates to that provider's `streamSimple` implementation.

## Error contract

A stream reports request failures through its terminal event and final `AssistantMessage`:

- `done` carries a successful message with `stopReason` `stop`, `length`, `toolUse`, or `deferred`.
- `error` carries a message with `stopReason` `error` or `aborted` and an `errorMessage`.
- Once streaming starts, provider failures do not escape as thrown loop errors.

`Models.streamSimple` and the bundled provider adapters implement this contract. A custom stream function must
do the same.

## Default stream function

Low-level callers may install a process-wide fallback:

```ts
import { setDefaultStreamFn } from "@june/core";

setDefaultStreamFn(streamFn);
```

Application hosts should normally inject `streamFn` explicitly so model runtime ownership is visible at the
composition root.

## Session-scoped options

`SimpleStreamOptions` includes cancellation, reasoning, retry, transport, cache, and session fields. The harness
sets cancellation and reasoning for each turn. A host can merge stable request metadata, as the CLI and desktop
do for `sessionId`, without changing the stored conversation.

Sessions persist neutral `Message` values. Provider adapters encode them only when a request is made and decode
provider events back into `AssistantMessageEvent` values before the loop sees them.
